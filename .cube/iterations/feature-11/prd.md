# 迭代 11 PRD：设置页信息架构、厂商配置、模板配置与数据安全

## 1. 功能概述

本次迭代将设置页重构为移动端可持续使用的配置入口页，并补齐真实配置闭环。设置首页只保留三个一级入口：厂商配置、模板配置、数据安全。

用户可以在厂商配置中管理多个 LLM 厂商连接，支持同一厂商下多个连接；可以在模板配置中维护模板、角色、模型与 Prompt 的绑定关系；可以在数据安全中完成设置导入导出、会话导出、本地数据清理与 API Key 安全说明。

本迭代以 `docs/prototype/settings-page-prototype-clickable-v2.html` 为交互原型，以 `docs/requirements/iteration-11-settings-provider-template-data-final.md` 为需求基线。若原型和需求存在表达差异，以需求文档中的最终需求与验收标准为准。

## 2. Functional Requirements

### 2.1 设置首页信息架构

#### FR-001（P0）设置首页只展示三个配置入口

- 功能点描述：设置首页只保留「厂商配置」「模板配置」「数据安全」三个大按钮入口。
- 输入：用户进入设置页。
- 输出：页面展示三个一级入口及对应说明文案。
- 异常处理：如果配置数据加载失败，设置首页入口仍应可见，并在进入对应二级页后展示具体错误状态。

#### FR-002（P0）移除独立模型与 Prompt 入口

- 功能点描述：设置首页不得展示 Provider 表单、模型配置表单、Prompt 配置表单，也不得出现「全局默认模型」「角色专属模型」「Prompt 提示词配置」等独立入口。
- 输入：用户浏览设置首页。
- 输出：用户只能看到本迭代定义的三个一级入口。
- 异常处理：无配置数据时也不得回退展示旧入口或裸露表单。

#### FR-003（P0）三个入口均可进入二级页面

- 功能点描述：点击「厂商配置」「模板配置」「数据安全」后，分别进入对应二级页面。
- 输入：用户点击设置首页入口。
- 输出：页面进入目标二级页，并提供清晰标题、说明和返回按钮。
- 异常处理：目标页面数据为空时展示空状态；数据加载失败时展示错误状态和可重试入口。

### 2.2 厂商配置

#### FR-004（P0）展示厂商连接列表

- 功能点描述：厂商配置页先展示连接列表，而不是直接展示新增或编辑表单。
- 输入：用户进入厂商配置页。
- 输出：展示所有已配置连接，包括连接名称、厂商类型、Base URL、模型数量、启用状态、最近测试状态。
- 异常处理：无连接时展示空状态和新增入口；加载失败时展示错误信息和重试入口。

#### FR-005（P0）支持同一厂商多个连接

- 功能点描述：用户可以为同一厂商配置多个连接，例如多个 OpenAI 链接。
- 输入：用户查看或新增连接。
- 输出：列表中允许出现相同厂商类型但不同连接名称、Base URL 和模型列表的多条连接。
- 异常处理：连接名称重复或信息不合法时，保存前提示用户修正。

#### FR-006（P0）新增厂商连接

- 功能点描述：厂商配置列表页右上角提供「＋」新增按钮，点击后进入新增连接表单。
- 输入：用户填写厂商类型、连接名称、Base URL、API Key、模型列表、Custom Header、启用状态。
- 输出：保存成功后返回厂商配置列表，并展示新增连接。
- 异常处理：必填项缺失、Base URL 不合法、模型列表为空或 Custom Header 格式不合法时，页面展示字段级错误；保存失败时展示失败原因。

#### FR-007（P0）编辑厂商连接

- 功能点描述：点击厂商连接卡片进入编辑页，用户可以修改连接配置。
- 输入：用户修改厂商类型、连接名称、Base URL、API Key、模型列表、Custom Header、启用状态。
- 输出：保存成功后返回连接列表，并展示更新后的连接信息。
- 异常处理：API Key 默认脱敏展示；用户未重新填写 API Key 时不得误清空原有 Key；保存失败时展示明确错误原因。

#### FR-008（P0）测试厂商连接

- 功能点描述：新增或编辑厂商连接时，用户可以点击「测试连接」验证连接可用性。
- 输入：当前表单中的连接配置或已保存连接。
- 输出：页面展示测试中、测试成功或测试失败状态；成功时可展示可用模型信息；失败时说明失败原因。
- 异常处理：Base URL 非法、API Key 不可用、网络失败、模型不可用等情况应给出可理解提示，不得暴露 API Key 明文。

#### FR-009（P0）删除厂商连接前检查影响

- 功能点描述：用户可以删除厂商连接，但如果连接已被模板角色引用，应阻止删除或提示影响范围。
- 输入：用户点击删除连接并确认。
- 输出：未被引用的连接被删除并从列表移除；被引用的连接显示无法删除或需先解除引用。
- 异常处理：删除失败时展示原因；确认弹窗不得泄露敏感信息。

### 2.3 模板配置

#### FR-010（P0）展示模板配置列表

- 功能点描述：点击「模板配置」进入模板列表页，展示可配置模板。
- 输入：用户进入模板配置页。
- 输出：展示模板名称、角色数、事件数、默认模型策略、配置状态。
- 异常处理：无模板时展示空状态和新增模板入口；加载失败时展示错误信息和重试入口。

#### FR-011（P1）新增模板

- 功能点描述：模板配置列表页右上角提供「＋」新增模板按钮，用户可创建新模板。
- 输入：模板名称、模板描述、默认模型策略等基础信息。
- 输出：保存成功后返回模板列表，并展示新模板。
- 异常处理：模板名称缺失或重复时提示用户修正；保存失败时展示失败原因。

#### FR-012（P0）查看和编辑模板详情

- 功能点描述：点击模板卡片进入模板详情页，用户可查看模板基础配置、默认模型策略、角色配置、事件与节奏相关摘要。
- 输入：用户点击模板卡片。
- 输出：展示模板详情，并提供保存、返回、编辑基础信息、角色配置等操作入口。
- 异常处理：模板不存在时展示未找到提示；加载失败时展示错误信息和返回入口。

#### FR-013（P0）在模板详情中维护角色模型与 Prompt

- 功能点描述：模型和 Prompt 跟随模板角色维护，每个角色可配置连接来源、模型、Temperature、Max Tokens、System Prompt，以及是否参与默认发言队列。
- 输入：用户进入角色编辑页并修改角色运行配置。
- 输出：保存成功后返回模板详情，角色卡片展示最新模型与配置状态。
- 异常处理：连接来源不存在、连接未启用、模型不可用、Prompt 为空或参数不合法时，保存前提示用户修正。

#### FR-014（P0）新增角色

- 功能点描述：模板详情页提供「＋ 新增角色」入口，用户可新增角色并配置模型与 Prompt。
- 输入：角色名称、角色定位、连接来源、模型、Temperature、System Prompt、启用状态等信息。
- 输出：保存成功后返回模板详情，角色列表出现新增角色。
- 异常处理：角色名称缺失或重复、模型配置不合法、Prompt 不符合要求时展示字段级错误。

#### FR-015（P1）复制和删除角色

- 功能点描述：角色编辑页提供复制角色与删除角色操作。
- 输入：用户点击复制或删除，并按页面提示确认。
- 输出：复制成功后生成新角色草稿或新角色；删除成功后角色从模板详情移除。
- 异常处理：主控角色或不可删除角色应禁止删除并提示原因；删除失败时展示失败原因。

#### FR-016（P0）模板默认模型策略

- 功能点描述：模板支持默认模型策略，例如智能 fallback、质量优先、成本优先。
- 输入：用户在模板基础配置或模板详情中选择策略。
- 输出：保存后模板详情和模板列表展示当前策略。
- 异常处理：策略缺失或与可用连接冲突时，保存前提示用户修正。

### 2.4 数据安全

#### FR-017（P0）展示数据安全功能列表

- 功能点描述：点击「数据安全」进入二级页，展示设置导出、设置导入、会话导出、本地数据清理、隐私说明。
- 输入：用户进入数据安全页。
- 输出：页面以列表形式展示各项数据安全能力及说明。
- 异常处理：相关能力不可用时展示禁用态和原因。

#### FR-018（P0）导出设置 JSON

- 功能点描述：用户可以导出设置 JSON，默认包含厂商连接脱敏信息、模板配置和数据偏好，不包含 API Key 明文。
- 输入：用户点击导出设置。
- 输出：生成可下载或可保存的设置 JSON。
- 异常处理：导出失败时展示错误原因；导出内容不得包含 API Key 明文。

#### FR-019（P1）导入设置 JSON

- 功能点描述：用户可以导入设置 JSON，并在正式覆盖前看到导入预检查结果。
- 输入：用户选择本地设置 JSON。
- 输出：页面展示将新增、覆盖、冲突或无效的配置项；用户确认后完成导入。
- 异常处理：文件格式不合法、结构不匹配、存在冲突或导入失败时展示明确提示，并不得部分静默覆盖用户配置。

#### FR-020（P0）导出会话 Markdown

- 功能点描述：数据安全页提供导出全部会话 Markdown 的入口，同时保留单个会话导出能力。
- 输入：用户点击导出会话。
- 输出：导出会话内容，且不包含 API Key 等敏感信息。
- 异常处理：无会话时展示空状态；导出失败时展示错误原因。

#### FR-021（P0）清理本地数据前二次确认

- 功能点描述：用户可清理本地数据，清理前必须展示二次确认，并可区分清缓存、清空会话、清空设置等范围。
- 输入：用户选择清理范围并确认。
- 输出：清理完成后展示成功提示，并反映最新数据状态。
- 异常处理：用户取消时不执行清理；清理失败时展示失败原因；操作不可逆时必须明确提示。

#### FR-022（P0）API Key 脱敏展示

- 功能点描述：API Key 在所有页面默认脱敏展示，导出、错误信息、测试结果和日志中不得出现明文 Key。
- 输入：用户查看、编辑、测试或导出设置。
- 输出：页面仅展示脱敏 Key 或空状态；用户可主动覆盖更新 Key。
- 异常处理：任何错误提示不得包含明文 Key 或敏感 Header 值。

## 3. Non-Functional Requirements

### 3.1 安全要求

- NFR-001（P0）：API Key 不得以明文出现在页面默认展示、导出文件、错误详情或测试结果中。
- NFR-002（P0）：导入设置必须先进行预检查，避免静默覆盖或破坏现有配置。
- NFR-003（P0）：清理本地数据属于高风险操作，必须二次确认并明确清理范围。
- NFR-004（P0）：删除被模板引用的厂商连接必须阻止或提示影响，避免模板运行配置失效。

### 3.2 移动端体验要求

- NFR-005（P0）：设置首页和所有二级配置页保持移动端单列布局。
- NFR-006（P0）：所有二级页必须提供返回按钮，所有可编辑页面必须提供明确保存操作。
- NFR-007（P1）：列表、表单、空状态、错误状态在移动端首屏内应保持可扫读，不把复杂配置堆叠在设置首页。

### 3.3 可用性要求

- NFR-008（P0）：连接测试失败、保存失败、导入失败、删除失败等场景必须给出用户可理解的原因。
- NFR-009（P1）：表单校验应尽量在保存前提示，减少用户提交后才发现错误。

### 3.4 兼容性要求

- NFR-010（P0）：底部一级导航保持为「首页 / 会话 / 模板 / 设置」。
- NFR-011（P0）：讨论页继续作为会话详情页存在，不新增为底部一级 Tab。
- NFR-012（P0）：单会话导出能力继续保留，不因数据安全页新增导出入口而移除。

## 4. 验收标准

### 4.1 设置首页

- AC-001：进入设置页时，只能看到「厂商配置」「模板配置」「数据安全」三个一级入口。
- AC-002：设置首页不展示 Provider 表单、模型配置表单、Prompt 配置表单。
- AC-003：设置首页不出现「全局默认模型」「角色专属模型」「Prompt 提示词配置」独立入口。
- AC-004：点击三个入口均可进入对应二级页面，并可通过返回按钮回到设置首页。

### 4.2 厂商配置

- AC-005：厂商配置页优先展示连接列表，列表卡片包含连接名称、厂商类型、Base URL、模型数量、启用状态和最近测试状态。
- AC-006：厂商配置页右上角存在「＋」新增入口，点击后进入新增连接表单。
- AC-007：用户可以创建多个相同厂商类型的连接，例如两个 OpenAI 连接。
- AC-008：点击连接卡片可进入编辑页，并可保存修改后返回列表。
- AC-009：新增和编辑表单包含厂商类型、连接名称、Base URL、API Key、模型列表、Custom Header、启用状态。
- AC-010：点击测试连接时，页面展示测试中、成功或失败状态，失败时给出可理解原因。
- AC-011：API Key 在列表、编辑页和测试结果中均不明文展示。
- AC-012：删除被模板引用的厂商连接时，系统阻止删除或明确提示影响范围。

### 4.3 模板配置

- AC-013：模板配置页展示模板名称、角色数、事件数、默认模型策略和配置状态。
- AC-014：模板配置页右上角存在「＋」新增模板入口。
- AC-015：点击模板卡片进入模板详情页。
- AC-016：模板详情页展示模板默认模型策略、角色配置、基础配置摘要。
- AC-017：点击角色卡片进入角色编辑页。
- AC-018：角色编辑页可以配置连接来源、模型、Temperature、Max Tokens、System Prompt。
- AC-019：模板详情页提供「＋ 新增角色」入口，新增角色保存后回到模板详情并出现在角色列表中。
- AC-020：角色引用不存在或未启用的连接、不可用模型时，保存被阻止并展示错误。

### 4.4 数据安全

- AC-021：数据安全页展示设置导出、设置导入、会话导出、本地数据清理、隐私说明。
- AC-022：导出设置 JSON 时，导出内容不包含 API Key 明文。
- AC-023：导入设置 JSON 时，正式导入前展示预检查结果。
- AC-024：导出会话 Markdown 时，不包含 API Key 或敏感 Header 值。
- AC-025：清理本地数据前必须出现二次确认；用户取消后不清理任何数据。
- AC-026：用户可选择清理范围，清理成功后页面展示成功状态并反映最新数据。

### 4.5 导航与布局

- AC-027：底部导航仍为「首页 / 会话 / 模板 / 设置」。
- AC-028：讨论页不作为底部一级 Tab 出现。
- AC-029：设置页及二级页在移动端保持单列布局。
- AC-030：所有二级页有返回按钮，所有编辑页有明确保存按钮。

## 5. Out of Scope

- 不做复杂模板画布编辑器。
- 不做模板市场。
- 不做多设备同步。
- 不做企业权限系统。
- 不做 API Key 云端托管加密方案；本迭代只要求不明文展示、不进入导出和错误信息。
- 不做 Provider 用量计费统计。
- 不新增讨论页为底部一级 Tab。
- 不把模型配置和 Prompt 配置恢复为设置首页独立入口。

## 6. 依赖说明

- 依赖现有设置模块、模板模块、LLM Provider 配置能力和本地存储能力。
- 依赖现有底部导航结构保持「首页 / 会话 / 模板 / 设置」。
- 依赖既有会话导出能力继续可用，并在数据安全页形成统一入口。
